# Prototype review record

Point-in-time review and delivery documents from the standalone agent-auth-plane
prototype, kept verbatim. They were written against that repository's nested
layout, so paths read as follows here:

| In the reviews | On this branch |
|---|---|
| `Datum-sync v1/datum_sync/...` | `datum_sync/...` |
| `local/...` | `demo/...` |
| `Datum-worker/...` | `worker/...` |
| `review/...` | `docs/review/...` |
| `Datum-harness/...` | the reference harness — not part of this repository |
| `review/checks.py` | historical defect probes tied to the harness — not ported |

- `REVIEW.md` — the security and design review of the supplied v1 code and the v2 proposal that shaped the prototype.
- `CREDENTIAL_ACCESS_REVIEW.md`, `MCP_FLEET_GOVERNANCE_REVIEW.md` — requirement checklists for managed credentials and fleet governance.
- `DELIVERY.md` — what the prototype delivered, migration by migration.
- `screenshots/` — the baseline portal capture regenerated by `demo/source_ui_check.py`.
